# CLAUDE.md — agent/

本目录用于记录 **Agent 实战任务** 的过程与成果，是招新作业的一部分，不是代码工程。
本文件只约束在 `agent/` 目录内的工作。

## 目录结构

```
agent/
├── CLAUDE.md      # 本文件：本目录的工作规则
├── NOTES.md       # 自我介绍 / 任务总述
└── notes/
    ├── note.md    # 任务过程记录（按 task 分节）
    └── *.png      # 记录中引用的截图
```

## 写作规则

- **语言**：所有文档用中文书写，术语（如 Agent、API、CLI）保留英文原文。
- **风格**：第一人称、口语化叙述实际操作过程，说明「做了什么、怎么做的、遇到什么问题、怎么解决的」。
- **不要**写成说明书或教程向的第三人称介绍——这是个人实践记录。
- 新增任务时，在 `notes/note.md` 中按 `## taskN` 顺序追加小节，不要打乱已有编号。

## 截图规则

- 图片统一放在 `notes/` 目录下，与 `note.md` 同级，禁止建立子文件夹。
- 引用使用相对路径：`![alt text](image-N.png)`，alt 文本用简短中文描述截图内容。
- 命名沿用现有 `image.png`、`image-1.png`、`image-2.png` … 的递增形式；
  粘贴产生的哈希文件名（如 `1ec7a729....png`）保留原样，不要改名以免链接失效。
- 提交前确认 `note.md` 中的每个图片链接都能在 `notes/` 中找到对应文件。

## 提交前检查

- `NOTES.md` 的自我介绍保持在 **约 100 字**，不要随意扩写。
- 文档中不写入 API Key、token、账号密码等敏感信息（截图同理，需打码）。
- 只改本目录内的文件；不要顺手修改仓库根目录或其他招新题目录。

## 仓库背景

- 仓库 `Jotang2026` 为招新学习与题目仓库，另有 `linux-shell-recruit/`、`make-cmake-recruit/`、`git/`、`test/` 等题目目录。
- 本目录的产出物会被人工阅读评审，可读性优先于「技术含量」。
