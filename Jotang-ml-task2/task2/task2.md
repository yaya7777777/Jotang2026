# Task 2: CNN 猫狗分类

## 实验 1：卷积核

### 1. 像素、RGB、灰度/彩色

- 像素：图片的最小单位，每个像素有 RGB 三个通道，值域 0-255
- RGB：红绿蓝三通道，每个通道 0-255，组合出 1600 万种颜色
- 灰度图：单通道，0-255 表示明暗
- 彩色图：三通道 RGB

### 2. Pillow → NumPy → Tensor

```python
shape: (256, 256, 3), dtype: uint8, min: 0, max: 255
HWC: (H, W, C) = (256, 256, 3)
CHW: (C, H, W) = (3, 256, 256)
```

- HWC：Pillow/NumPy 默认，人读方便
- CHW：PyTorch 默认，GPU 并行计算方便（通道在前，批量矩阵乘法）

### 3. 卷积核是什么

卷积核是一个小矩阵（如 3×3），在图片上从左到右、从上到下滑动，每到一个位置就与覆盖的像素区域做**逐元素相乘再求和**，得到输出特征图的一个像素。

### 4. 手写 2D 卷积

代码见 `conv2d.py`，核心逻辑：
- 双重循环遍历输出特征图的每个位置
- 取出输入图片对应区域与卷积核逐元素相乘
- 求和写入输出

### 5. 四种核处理结果

![四种卷积核](results/conv2d_kernels.png)

| 核类型 | 效果 | 原因 |
|---|---|---|
| 均值模糊 3×3 | 图片变模糊 | 邻域平均，边缘被平滑 |
| 高斯模糊 5×5 | 图片变模糊但更自然 | 中心权重大，远处权重小，符合人眼 |
| 锐化 | 边缘更明显 | 中心减四周，突出差异 |
| Sobel-X/Y | 检测垂直/水平边缘 | 左减右/上减下，边缘处差异大 |

### 6. 为什么

- 均值/高斯模糊：邻域内像素值被平均，边缘两侧像素互相混合，过渡变平滑
- 锐化：中心像素乘以 5，四周乘以 -1，中心与四周差异被放大
- Sobel：左减右（Sobel-X）在垂直边缘处差异最大，上减下（Sobel-Y）在水平边缘处差异最大

### 7. valid vs same padding

```
valid 输出尺寸: (254, 254, 3)
same 输出尺寸: (256, 256, 3)
```

| padding | 输出尺寸 | 边缘像素 |
|---|---|---|
| valid | (H-k+1, W-k+1) | 边缘信息丢失 |
| same | (H, W) | 用 0 填充，边缘保留 |

公式：`out = (H + 2p - k) / s + 1`

## 实验 2：猫狗分类 CNN

### 1. 数据集

Kaggle Dogs vs Cats，训练集 25000 张（猫 12500 + 狗 12500），测试集 12500 张。图片尺寸不一，背景各异。

### 2. 数据预处理

- 统一缩放到 64×64
- 训练集：随机水平翻转 + 随机裁剪 + 颜色扰动
- 验证/测试集：只做缩放
- ToTensor 自动归一化到 [0,1] 并转 CHW

### 3. CNN 结构

```python
conv1: (3, 64, 64) → (32, 64, 64)
pool1: (32, 64, 64) → (32, 32, 32)
conv2: (32, 32, 32) → (64, 32, 32)
pool2: (64, 32, 32) → (64, 16, 16)
conv3: (64, 16, 16) → (128, 16, 16)
pool3: (128, 16, 16) → (128, 8, 8)
fc1: 8192 → 256
fc2: 256 → 2
```

### 4. 每层 Tensor 形状

见上面，宽高逐层减半，通道数逐层翻倍。

### 5. 特征图可视化

![第一层特征图](results/feature_maps.png)

16 个通道分别关注：边缘、纹理、颜色、局部形状。

### 6. 数据增强对照

![数据增强](results/augmentation.png)

- 随机水平翻转：猫狗左右对称，合理
- 随机裁剪：可能裁掉主体，需控制 padding
- 颜色扰动：猫狗颜色多样，合理
- 随机旋转：猫狗不会倒过来，可能破坏标签

### 7. 错误样本分析

![混淆矩阵](results/confusion_matrix.png)

错误样本多为：背景复杂、主体小、角度刁钻、猫狗特征相似（如黑猫 vs 黑狗）。

## 趁热打铁

### 1. 卷积为什么比全连接更适合图片

- 全连接：参数爆炸（64×64×3=12288 输入，第一层就 12288×256=314 万参数），且破坏空间结构
- 卷积：参数共享（3×3 核只有 9 个参数），保留空间局部性，平移不变性

### 2. 输入/输出通道与卷积核数量

- 输入通道 = 上一层特征图通道数
- 输出通道 = 当前层卷积核数量
- 每个卷积核产生一个输出通道

### 3. padding/stride/pooling 计算

以 conv1 为例：输入 64×64，k=3，p=1，s=1
- 输出 = (64 + 2×1 - 3)/1 + 1 = 64×64
- pool1：k=2，s=2，输出 = 64/2 = 32×32

### 4. 宽高变小通道变多

- 池化把宽高减半，提取更抽象特征
- 通道数翻倍，补偿空间信息损失，保留更多特征组合

### 5. 激活函数和损失函数

- ReLU：隐藏层默认，梯度恒 1，计算快
- CrossEntropyLoss：二分类，内部 log_softmax + NLLLoss，不需要手动 Softmax

### 6. 数据增强为什么训练集和验证集/测试集不能一样

- 训练集增强：增加多样性，防止过拟合
- 验证/测试集：模拟真实场景，必须固定预处理，否则评估不准
- 翻转/裁剪/颜色扰动在验证集上可能破坏标签（如把猫裁成狗）

## 拓展

### 1. AlexNet / VGG / ResNet 对比

| 模型 | 层数 | 卷积核 | 参数量 | 创新 |
|---|---|---|---|---|
| AlexNet | 8 | 11×11, 5×5, 3×3 | 60M | 首次深度 CNN，ReLU+Dropout |
| VGG | 16-19 | 全部 3×3 | 138M | 小核堆叠，结构统一 |
| ResNet | 18-152 | 3×3 + 残差连接 | 25M | 残差连接解决梯度消失 |

### 2. 第一层 vs 最后一层特征图 L2 范数

- 第一层：L2 范数大，响应强烈，关注边缘/纹理
- 最后一层：L2 范数小，响应稀疏，关注语义特征（猫脸/狗脸）

### 3. BasicBlock vs Bottleneck

- BasicBlock：2 个 3×3 卷积，ResNet-18/34 用，参数少
- Bottleneck：1×1 降维 + 3×3 + 1×1 升维，ResNet-50/101/152 用，参数多但计算高效

### 4. 手写经典网络

见 `resnet.py`，用 BasicBlock 实现 ResNet-18 主干。
